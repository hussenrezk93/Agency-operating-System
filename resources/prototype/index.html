Workflow & Task Management — Interactive Frontend Demo (BRD v1.1 · ERD v1.2)
Interactive frontend demo for management. No backend yet — everything runs in the browser with realistic demo data saved in LocalStorage. Sign in to start: username manager (or admin / tl / employee), password Demo123!. Use the black Demo Role Switcher (bottom corner) to jump roles and screens, and EN / عربي to flip language and direction. Full walkthrough in README.md.

1 · Login page

Username + password, no self-registration, AR/EN toggle.

2 · Manager view

Full operational control: KPIs, needs-attention queue, departments, temp TLs.

3 · Team Leader view

Waiting-assignment queue, review queue, My Tasks, first-seen tracking.

4 · Employee view

Assigned work, current-month score, due-soon reminders.

5 · Admin view

Configuration only: routing rules, output access, managers, audit — no task content.

6 · Task workflow

The signature route rail: department hand-offs, timeline, outputs, review.
